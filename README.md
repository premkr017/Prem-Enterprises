## 📋 Overview

**Prem Enterprises** is a premium IT solutions & cyber security brand founded by **Prem Kumar** (CEO) and **Ritik Kumar** (Owner). Based in **Ramgarhwa, East Champaran, Bihar**, we provide affordable, secure, and smart technology solutions — from Windows/Linux formatting to ethical hacking and student assistance.

Our mission is to **revive old computer systems** and make technology accessible to students, small businesses, and rural users — without requiring costly hardware upgrades.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/prem-enterprises.git
cd prem-enterprises
```

### 2. Open the website

Simply open the `index.html` file in any modern web browser:

```bash
# On Windows
start index.html

# On macOS
open index.html

# On Linux
xdg-open index.html
```

> **No build tools, no dependencies, no server required.** Just double-click and go!
